# School Voting — MVP

Красивый школьный конкурс с голосованием учеников и родителей.

## Что есть
- 9 классов-кандидатов: 5А, 8А, 7Б, 5Б, 10Г, 10А, 7А, 6А, 10Б.
- Форма ученика: имя, фамилия, класс.
- Форма родителя: ФИО родителя + ФИО ребёнка + класс ребёнка.
- CAPTCHA-поле и поддержка Cloudflare Turnstile через переменные окружения.
- Серверная проверка.
- Проверка повторного голосования по нормализованным данным.
- Ограничение частых голосований с одного подключения.
- Закрытая админ-страница с данными голосующих и подозрительными записями.

## Запуск
1. `npm install`
2. Создайте `.env` по `.env.example`.
3. Укажите `DATABASE_URL`.
4. `npx prisma db push`
5. `npm run seed`
6. `npm run dev`

Для публичного запуска используйте Vercel + PostgreSQL (например, Neon). Для настоящей CAPTCHA укажите Cloudflare Turnstile `TURNSTILE_SECRET_KEY` и `NEXT_PUBLIC_TURNSTILE_SITE_KEY` и добавьте виджет Turnstile на клиентскую форму.

**Важно:** текущая админ-страница MVP ещё требует отдельной авторизации перед реальным использованием. Не публикуйте её с персональными данными без защиты доступа.
